# Lab Sheet 8 — Flutter SQLite Applications

Each numbered Dart file corresponds to one of the 17 programs in `8.pdf`. Examples are independent Flutter entry points. Copy one file into `lib/main.dart` at a time, or run the selected Dart file from a Flutter project.

Add `sqflite` and `path` to the project (for example, `flutter pub add sqflite path`). SQLite database files are created on first launch.

Questions 1–17 cover Notes, Contact Book, Expense Tracker, To-Do, Registration/Login, validation, student screens, inventory, and shopping cart examples.

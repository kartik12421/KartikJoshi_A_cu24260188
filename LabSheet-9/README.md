# Lab Sheet 9 — Flutter REST API Integration and JSON Parsing

Each numbered Dart file answers the matching question in `9.pdf`. Questions 1 and 2 are standalone Dart console programs. Questions 3–15 are independent Flutter app entry points: copy one file at a time to `lib/main.dart` in a Flutter project.

Add the HTTP client dependency with `flutter pub add http`. Run a Flutter example with `flutter run` after copying the chosen file. The examples use JSONPlaceholder for posts/users and Fake Store API for products; they need an internet connection at runtime.

Files are numbered `01` through `15` to match the worksheet.
